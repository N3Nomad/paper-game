# Камень, ножницы, бумага

Браузерная игра «Камень, ножницы, бумага» против компьютера. Проект из курса [The Odin Project](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors).

**[Играть онлайн](https://n3nomad.github.io/paper-game/)**

## Как играть

- Нажми на одну из кнопок: камень, ножницы или бумага.
- Компьютер делает случайный выбор, и на экране видно оба хода и результат раунда.
- За победу в раунде начисляется очко, ничья очков не даёт.
- Побеждает тот, кто первым наберёт 5 очков. Следующий клик начинает новую партию.

## Технологии

HTML, CSS, JavaScript. Без библиотек и фреймворков.

## Чему я научился

- Писать функции с параметрами и возвращать из них значения через `return`
- Понимать область видимости: где переменная доступна, а где нет
- Использовать условия, логические операторы и цикл `for`
- Находить элементы на странице и менять их текст через DOM
- Обрабатывать клики через `addEventListener`
- Выносить повторяющийся код в отдельную функцию
- Верстать с помощью Flexbox
- Работать с ветками в git: разработка в `rps-ui` и слияние в `main`

## Развитие

Первая версия игры работала в консоли через `prompt`. Её можно найти в истории коммитов. Затем интерфейс перевели на кнопки и вывод результата на страницу.
